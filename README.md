# CP1404 Practicals
## About repository
Practical work for IT@JCU CP1404, practicing how to write code in a clean and clear way so that most programmers can
read and understand the code, using common conventions from the programming patterns page supplied by CP1404.

Some of the strategies learnt from this subject include:

- Common naming conventions for variables (e.g. local, CONSTANT, arrays, Class)
- Commiting for every small milestone that you believe to achieve to github
- Documenting as much as possible to make code more clear
